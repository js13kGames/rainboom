Rainboom is a tiny incremental arcade game about completing rainbows. Blast unfinished arcs, trigger chain reactions, collect upgrades, and build increasingly ridiculous rainbow-powered abilities as you fill the sky with color.

Intended to be played with a VR headset, but this version also plays on web desktop.

🌈 Made for js13kGames 2026, an annual game development competition where the entire game must fit within just 13KB. The theme was Unicorns and Rainbows.
